## Step 1: Linux host 8.8.8.8-তে পৌঁছাতে চায়

Linux host ইন্টারনেটে **8.8.8.8** (Google DNS) ping করতে চায়।

সে কিভাবে এই ডেস্টিনেশনে পৌঁছানো যায় তা নির্ধারণ করতে হবে — এখন **routing table** চেক করার সময়।

**পূর্বশর্ত:** আগে **Route Table** (ip route basics) এবং **Default Gateway** (ধারণা) বোঝা প্রয়োজন।

## Step 2: স্থানীয় routing table চেক করুন

কার্নেল routing table-তে মিল খুঁজে দেখে:
`ip route show`

routing table-তে সংযুক্ত রুট এবং যেকোনো স্ট্যাটিক রুট থাকে। host 8.8.8.8-র জন্য রুট খুঁজে দেখে।

## Step 3: 8.8.8.8-র জন্য কোনো নির্দিষ্ট রুট নেই — ডিফল্ট ব্যবহার করুন

routing table-তে 8.8.8.8-র জন্য কোনো নির্দিষ্ট এন্ট্রি নেই।

কার্নেল **ডিফল্ট রুট** (0.0.0.0/0)-তে ফিরে যায় — এটা আরও নির্দিষ্ট রুটে না পড়া যেকোনো ডেস্টিনেশনের জন্য কাজ করে।

## Step 4: ডিফল্ট রুট: via 192.168.1.1 dev eth0

ডিফল্ট রুট নির্ধারণ করে:
`default via 192.168.1.1 dev eth0`

এর মানে: সব মিলানো না যাওয়া traffic **192.168.1.1** (Router)-র কাছে **eth0** ইন্টারফেস দিয়ে পাঠাও।

## Step 5: Packet: Host → eth0

কার্নেল ICMP Echo packet তৈরি করে এবং প্রেরণের জন্য **eth0**-কে দেয়।

frameটা Router-এর MAC-এ ঠিকানা করা (192.168.1.1-র জন্য ARP সমাধান করা হয়েছে)।

## Step 6: eth0 Router (192.168.1.1)-কে পাঠায়

packet eth0 থেকে **Router** (ডিফল্ট গেটওয়ে)-র কাছে যায়।

Router তার LAN ইন্টারফেস (192.168.1.1)-তে packet গ্রহণ করে এবং ডেস্টিনেশন IP চেক করে।

## Step 7: Router ইন্টারনেটের দিকে ফরওয়ার্ড করে

Router packet গ্রহণ করে এবং **NAT** (Network Address Translation) সম্পন্ন করে, প্রাইভেট সোর্স IP কে তার পাবলিক IP দিয়ে প্রতিস্থাপন করে।

তারপর packetটা ইন্টারনেটের দিকে ফরওয়ার্ড করে।

## Step 8: উত্তর ফিরে আসে

ইন্টারনেট host (8.8.8.8) Router-এর পাবলিক IP-তে উত্তর দেয়।

Router উত্তর গ্রহণ করে এবং NAT table-তে খুঁজে দেখে প্রাইভেট IP-তে ফিরিয়ে দেয়।

## Step 9: Router NAT অনুবাদ করে, Host-কে পাঠায়

Router রিভার্স NAT সম্পন্ন করে:
`Public IP → 192.168.1.10`

সে অনুবাদ করা উত্তরটা Linux Host-কে eth0 দিয়ে ফরওয়ার্ড করে।

## Step 10: ডিফল্ট গেটওয়ে রাউটিং সম্পূর্ণ!

**মূল কথা:** ডিফল্ট গেটওয়ে হলো স্থানীয় routing table-তে না থাকা যেকোনো ডেস্টিনেশনের জন্য **ফলব্যাক রুট**।

কিভাবে কাজ করেছে:
1. Host 8.8.8.8-র জন্য routing table চেক করে — **মিলেনি**
2. **ডিফল্ট রুট** (0.0.0.0/0)-তে ফিরে যায়
3. ডিফল্ট via **192.168.1.1** (Router)
4. Packet Router-কে পাঠানো হয় → NAT → ইন্টারনেট
5. উত্তর NAT-এর মাধ্যমে ফিরে আসে

কনফিগার করুন:
`ip route add default via 192.168.1.1`
`ip route show`
