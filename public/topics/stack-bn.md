## Step 1: অ্যাপ একটা রিমোট সার্ভারে ডেটা পাঠাতে চায়

একটা **ইউজার অ্যাপ্লিকেশন** (যেমন curl, ব্রাউজার) `10.0.0.50`-তে একটা রিমোট সার্ভারে ডেটা পাঠাতে চায়।

তারে (wire) ট্রান্সমিট করার আগে ডেটাকে **TCP/IP নেটওয়ার্ক স্ট্যাকের** প্রতিটা লেয়ার দিয়ে নিচে নামতে হবে।

**পূর্বশর্ত:** **TCP হ্যান্ডশেক** ও **DNS** বিষয়গুলো বুঝো যাতে জানো অ্যাপ্লিকেশনগুলো স্ট্যাক কীভাবে ব্যবহার করে।

**আরও দেখো:** **TCP/UDP পোর্ট** ও **IP এড্রেস** বিষয়গুলো প্রতিটা লেয়ারের হেডারের জন্য।

## Step 2: অ্যাপ্লিকেশন send() কল করে — ডেটা Socket API-তে প্রবেশ করে

অ্যাপ্লিকেশন `send()` সিস্টেম কল করে। ডেটা **Socket API** লেয়ারে প্রবেশ করে — এটাই ইউজার স্পেস ও কার্নেল স্পেসের মাঝের সীমানা।

Socket API নেটওয়ার্ক যোগাযোগের জন্য একটা স্ট্যান্ডার্ডাইজড ইন্টারফেস প্রদান করে।

## Step 3: Socket API ডেটা TCP লেয়ারে পাঠায়

Socket API ডেটা কার্নেলের **TCP লেয়ারে** হাতে দেয়।

TCP নির্ভরযোগ্যতা, সিকোয়েন্সিং, ফ্লো কন্ট্রোল, ও কংজেশন ম্যানেজমেন্ট হ্যান্ডেল করবে। ডেটাকে একটা TCP সেগমেন্টে রাখা হয়।

## Step 4: TCP হেডার যোগ করে: পোর্ট, seq/ack নম্বর

TCP লেয়ার ডেটাকে একটা **TCP হেডার** দিয়ে মুড়ে দেয়:
`Source Port: 49152`
`Dest Port: 80`
`Seq: 1000`
`Ack: 0`
`Flags: SYN`

এই সেগমেন্ট এখন IP লেয়ারে পাঠানোর জন্য প্রস্তুত।

## Step 5: TCP সেগমেন্ট IP লেয়ারে পাঠায়

TCP সেগমেন্ট নিচে **IP লেয়ারে** পাঠানো হয়। IP নেটওয়ার্কের মধ্যে রাউটিং করার জন্য এটাকে একটা IP হেডার দিয়ে মুড়ে দেবে।

## Step 6: IP হেডার যোগ করে: src/dst IP, TTL, প্রোটোকল

IP লেয়ার TCP সেগমেন্টকে একটা **IPv4 হেডার** দিয়ে মুড়ে দেয়:
`Src IP: 192.168.1.10`
`Dst IP: 10.0.0.50`
`TTL: 64`
`Protocol: TCP (6)`

IP প্যাকেট এখন NIC ড্রাইভারের জন্য প্রস্তুত।

## Step 7: IP ফ্রেম NIC ড্রাইভারে পাঠায়

IP লেয়ার প্যাকেট **NIC ড্রাইভারে** হাতে দেয়। ড্রাইভার সেটাকে ট্রান্সমিট করার জন্য ফিজিক্যাল NIC (eth0)-তে দেবে।

## Step 8: NIC MAC হেডার যোগ করে, তারে ট্রান্সমিট করে

NIC সোর্স ও ডেস্টিনেশন MAC এড্রেস সহ **Ethernet II হেডার** যোগ করে, FCS গণনা করে, এবং ফ্রেমকে ফিজিক্যাল তারে ট্রান্সমিট করে।

`Src MAC: AA:BB:CC:DD:EE:01 (eth0)`
`Dst MAC: Default Gateway MAC`

## Step 9: সুইচ রিমোট সার্ভারের দিকে ফরোয়ার্ড করে

**সুইচ** ফ্রেম গ্রহণ করে, তার ফরোয়ার্ডিং টেবিলে ডেস্টিনেশন MAC খুঁজে বের করে, এবং ফ্রেমকে রিমোট সার্ভারের দিকে ফরোয়ার্ড করে।

## Step 10: সার্ভার NIC ফ্রেম গ্রহণ করে

**রিমোট সার্ভারের NIC** ফ্রেম গ্রহণ করে, ডেস্টিনেশন MAC চেক করে — ম্যাচ হয়েছে! NIC Ethernet হেডার সরিয়ে IP প্যাকেটকে সার্ভারের নেটওয়ার্ক স্ট্যাকের উপরে পাঠায়।

সার্ভারের NIC CPU-কে নোটিফাই করতে ইন্টারাপ্ট ট্রিগার করে।

## Step 11: সার্ভার স্ট্যাকের উপরের দিকে প্রসেস করে

রিমোট সার্ভার প্যাকেটকে তার নিজের নেটওয়ার্ক স্ট্যাকের মধ্য দিয়ে **উপরের দিকে** প্রসেস করে:

`NIC Driver → IP Layer → TCP Layer → অ্যাপ্লিকেশন`

প্রতিটা লেয়ার তার হেডার সরিয়ে পেলোডকে উপরে পাঠায় — পাঠানো হোস্টের কাজের বিপরীত।

## Step 12: সম্পূর্ণ যাত্রা শেষ!

**মূল কথা:** ডেটা পাঠানো হোস্টের স্ট্যাকে **নিচে** যায়, তারের মধ্য দিয়ে যায়, তারপর গ্রহণকারী হোস্টের স্ট্যাকে **উপরে** যায়।

পুরো যাত্রা:
1. **অ্যাপ্লিকেশন** → Socket API (`send()`)
2. **TCP** পোর্ট, সিকোয়েন্স নম্বর যোগ করে
3. **IP** সোর্স/ডেস্টিনেশন IP, TTL যোগ করে
4. **NIC** MAC হেডার যোগ করে, ট্রান্সমিট করে
5. **সুইচ** গন্তব্যে ফরোয়ার্ড করে
6. সার্ভার NIC গ্রহণ করে, MAC হেডার সরায়
7. **IP** IP হেডার সরায়
8. **TCP** TCP হেডার সরায়, ডেটা ডেলিভারি করে
9. **অ্যাপ্লিকেশন** ডেটা পায়!

প্রতিটা লেয়ার শুধু তার অপর পাশের **পিয়ারের** সাথে কথা বলে (TCP-to-TCP, IP-to-IP, MAC-to-MAC)।
